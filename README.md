🚀 Project Overview
This project involves designing a highly available ISP network for "ConnectSphere." The goal is to connect three cities (City A, B, and C) in a triangle topology using Cisco routers. We are implementing static routing with floating backup paths to ensure that if the primary link between City A and City B fails, traffic reroutes through City C in under 60 seconds.
